# Polymarket · 隐藏原生曲线

Chrome 扩展，当前版本 **1.0.15**。

## 功能

- 隐藏原生曲线、指定标题、交易条款提示和右侧推荐区域。
- 隐藏左侧不断飘动的红绿成交金额和 ROI 浮层。
- 在价格盘口页面隐藏左上角及倒计时旁的 Polymarket Logo。
- 保留目标价格、当前价格、倒计时和交易按钮。
- 点击左侧期次时完整加载页面。
- BTC 涨跌页面增加「趋势」按钮，在新标签页打开币安 BTC/USDT 现货页面。
- 在 BTC 5／15 分钟页面的「趋势」右侧，以两行普通文字显示24小时、1小时的最长连续 up 和 down 期数；不含当前运行期，上一期尚未公布时按同源价格暂判，官方结果到达后替换，悬停可查看说明。
- 刚结束的 5／15 分钟盘口尚未显示官方方向时，在期次文字右侧加虚线圈绿色 ↑／红色 ↓，用目标价和结束价暂判；相等算 UP，官方结果圆点出现后移除临时箭头。

## 安装

1. 从仓库的 Releases 下载 `polymarket-hide-chart.zip`，解压。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 刷新 Polymarket 页面。

更新时替换文件，在扩展卡片点击「重新加载」，再刷新页面。停用时关闭或移除此扩展，再刷新页面。

详细说明见 [安装说明](安装说明.md)，历史验证范围见 [验收记录](验收记录.md)。

## 适用范围

最低 Chrome 105，仅在 `polymarket.com` 及其 `www` 域名生效。扩展调整页面展示与导航，不访问钱包或交易接口。网站结构变化后，规则可能需要更新。

本版本保留网站原有响应式布局。临时箭头采用虚线圈，与官方实心圆点区别；悬停可查看目标价、结束价和暂判说明，不代表官方结算结果。价格接口暂未更新时，尝试读取该期页面原生曲线的价格数据；缺少可靠数值时不猜方向。

支持新局只有预载价格、尚未发起价格请求的情况。跨局时保留最近的公开价格记录；对于同币种、同周期且首尾相接的两局，严格核对时间、价格类型和 TWAP 设置后，可用新局的目标价作为上一局的同源边界价暂判，随后用原站结束价校正。不会把新局不断变化的当前价当成上一局结果。

上一局价格接口已提供目标价时，直接与新局目标价比较，不再等待旧页面加载。站内切换后没有对应预载查询时，可读取页面标明的目标价；显示精度不足以确认方向时继续等待原始数据。

## 连续期数统计

两行普通文字分别统计最近 24 小时、1 小时范围内的最长连 up 和最长连 down，不是当前尾部正在延续的连胜次数。范围截止到当前运行期的开始：5 分钟页面分别覆盖前 288／12 个完整窗口，15 分钟页面覆盖前 96／4 个完整窗口；即使浏览历史期次，也按当前时间统计。不使用卡片、彩色数字或统计箭头。

官方结果优先。上一期尚无官方结果时，读取该期目标价与结束价，或使用同源、同均价设置的下一期开盘边界价计算方向；相等算 UP，暂判与数据完整性说明放在悬停提示中。缺少可靠数值时连续段在缺期处中断；`≥` 表示已知数据可确认的下限，不将不完整结果作为精确最大值。

统计只通过浏览器当前网络读取 Polymarket 同站公开接口，沿用浏览器代理，无额外代理或后台服务。每次最多查询 50 期、并发最多两批；浏览器标签会缓存较早的已确认结果，约每 15 秒复核近期结果，新一期开局时自动更新范围。
